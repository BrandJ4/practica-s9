## Checklist de implementación

- [ ] Documentar interfaces/contratos de cada módulo
- [ ] Crear rama de integración
- [ ] Sesión conjunta de revisión de interfaces
- [ ] Identificar y listar todas las incompatibilidades
- [ ] Resolver incompatibilidades con responsabilidad clara
- [ ] Escribir tests de integración
- [ ] Code review cruzado (cada subgrupo revisa código del otro)
- [ ] Integración gradual: un módulo a la vez
