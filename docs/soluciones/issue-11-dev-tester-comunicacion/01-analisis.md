# Issue #11 - Falta de comunicación entre desarrolladores y testers

## Descripción del problema
Desarrolladores y testers trabajan de forma aislada. Los developers entregan código sin contexto y los testers descubren bugs tardíamente, causando ciclos lentos de feedback y retrasos.

## Impacto
- Bugs detectados tarde en el ciclo de desarrollo (más costosos de corregir)
- Desarrolladores que no entienden qué se está probando
- Testers que no conocen las áreas de mayor riesgo
