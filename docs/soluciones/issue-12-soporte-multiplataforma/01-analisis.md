# Issue #12 - Cliente solicita soporte multiplataforma

## Descripción del problema
El cliente requiere que la aplicación funcione en múltiples sistemas operativos (Windows, Linux, macOS), pero el equipo solo tiene experiencia desarrollando para uno de ellos.

## Impacto
- Código no portable con dependencias específicas de un OS
- Falta de ambientes de prueba para otras plataformas
- Curva de aprendizaje adicional para el equipo
