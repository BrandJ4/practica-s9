# Issue #13 - Automatización de pruebas y CI/CD

## Descripción del problema
El equipo debe implementar pruebas automatizadas y un pipeline de integración/entrega continua, pero ningún miembro tiene experiencia previa con estas herramientas.

## Impacto
- Pruebas manuales lentas y propensas a error humano
- Sin validación automática en cada cambio de código
- Deployments manuales y riesgosos
