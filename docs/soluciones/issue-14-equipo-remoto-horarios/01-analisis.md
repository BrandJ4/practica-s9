# Issue #14 - Equipo remoto con horarios incompatibles

## Descripción del problema
Parte del equipo trabaja de forma presencial y otra parte remotamente con diferencias horarias significativas, dificultando la comunicación en tiempo real y la colaboración.

## Impacto
- Reuniones imposibles de coordinar para todos
- Decisiones tomadas sin input de parte del equipo
- Sensación de exclusión en miembros remotos
