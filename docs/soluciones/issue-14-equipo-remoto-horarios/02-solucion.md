## Solución propuesta

### 1. Definir ventana de overlap
Identificar las horas en que todos están disponibles simultáneamente y reservarlas para reuniones críticas.

Ejemplo con equipos en Lima (GMT-5) y Madrid (GMT+2):
```
Lima:   9am-6pm  →  Madrid: 4pm-1am
Overlap: 9am-12pm Lima = 4pm-7pm Madrid
```

### 2. Comunicación asíncrona como default
- Todas las decisiones importantes se documentan en GitHub Issues/PRs
- No se espera respuesta inmediata fuera del horario acordado
- Los comentarios en PRs deben ser suficientemente claros para entenderse sin reunión

### 3. Reuniones grabadas
Toda reunión que tome decisiones importantes se graba y se comparte el link + resumen escrito.

### 4. Daily asíncrono
En lugar de reunión diaria, cada miembro publica en el canal del equipo:
```
📅 [Fecha]
✅ Completé: ...
🔄 Trabajaré en: ...
🚧 Bloqueos: ...
```
