# Issue #15 - Base de datos no soporta funcionalidades clave

## Descripción del problema
Durante el desarrollo se descubre que la base de datos seleccionada al inicio del proyecto no soporta características necesarias como búsqueda full-text, datos geoespaciales, o transacciones complejas.

## Impacto
- Necesidad de migración o cambio de tecnología
- Tiempo perdido en desarrollo sobre una base inadecuada
- Riesgo de pérdida de datos durante la migración
