# Issue #16 - Falta de criterios claros para revisión de código

## Descripción del problema
El equipo no tiene una guía definida para hacer code reviews. Cada revisor usa criterios distintos, generando conflictos sobre qué es "calidad suficiente" y revisiones inconsistentes.

## Impacto
- PRs rechazados por razones subjetivas o inconsistentes
- Conflictos interpersonales sobre preferencias de código
- Code reviews que no agregan valor real
