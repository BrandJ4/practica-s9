# Issue #2 - Conflictos de merge durante integración de código

## Descripción del problema
Al integrar ramas de diferentes desarrolladores, se generan múltiples conflictos de merge que consumen tiempo y pueden introducir errores en el código base.

## Impacto
- Tiempo perdido resolviendo conflictos manualmente
- Riesgo de pérdida de código funcional
- Retrasos en el pipeline de entrega
