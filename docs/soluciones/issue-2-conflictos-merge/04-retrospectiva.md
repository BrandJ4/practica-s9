## Retrospectiva

### ¿Qué aprendimos?
Los conflictos de merge son síntoma de falta de coordinación, no solo un problema técnico. La solución combina proceso + disciplina de equipo.

### Comandos útiles aprendidos
```bash
git log --oneline --graph --all   # Ver árbol de ramas
git diff develop...feature/mi-rama  # Ver diferencias antes del merge
git mergetool                      # Resolver conflictos con herramienta visual
```
