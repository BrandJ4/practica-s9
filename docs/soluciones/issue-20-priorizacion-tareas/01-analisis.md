# Issue #20 - Dificultad para priorizar tareas críticas

## Descripción del problema
El equipo tiene dificultades para distinguir qué tareas son verdaderamente críticas y cuáles son secundarias, resultando en esfuerzo invertido en features de bajo impacto mientras funcionalidades clave se retrasan.

## Impacto
- Features importantes sin completar al final del sprint
- Esfuerzo invertido en tareas de bajo valor
- Cliente insatisfecho con las prioridades del equipo
