# Issue #3 - Dificultades para documentar correctamente el código

## Descripción del problema
El código del proyecto carece de documentación adecuada: sin comentarios, sin README actualizado, sin especificación de funciones. Esto dificulta el mantenimiento y la incorporación de nuevos miembros.

## Impacto
- Tiempo excesivo para entender código ajeno
- Errores al modificar funciones mal comprendidas
- Onboarding lento de nuevos desarrolladores
