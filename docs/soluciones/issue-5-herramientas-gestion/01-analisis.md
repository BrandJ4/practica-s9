# Issue #5 - Descoordinación por uso de diferentes herramientas de gestión

## Descripción del problema
Cada miembro del equipo usa su herramienta preferida (Trello, Notion, Excel, sticky notes) para gestionar sus tareas, lo que impide tener visibilidad unificada del avance del proyecto.

## Impacto
- Imposibilidad de conocer el estado real del proyecto
- Duplicación de tareas o tareas que nadie hace
- Reuniones de sincronización más largas y menos efectivas
