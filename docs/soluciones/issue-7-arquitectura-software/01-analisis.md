# Issue #7 - Miembro del equipo no entiende la arquitectura del software

## Descripción del problema
Un desarrollador comete errores recurrentes porque no comprende bien cómo está estructurado el sistema, cómo fluyen los datos o cuáles son las responsabilidades de cada capa.

## Impacto
- Bugs recurrentes en áreas específicas
- Código que no sigue el patrón arquitectónico del proyecto
- Deuda técnica acumulada
