# Issue #8 - Falta de acuerdo sobre herramienta de control de versiones

## Descripción del problema
El equipo no llega a un consenso sobre qué sistema de control de versiones usar, con algunos proponiendo Git, otros SVN, y otros sin experiencia en ninguno.

## Impacto
- Imposibilidad de colaborar en el código
- Riesgo de pérdida de trabajo
- Tiempo perdido en debate sin resolución
