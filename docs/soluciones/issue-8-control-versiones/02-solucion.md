## Solución propuesta

### Decisión: Git + GitHub
Git es el estándar de la industria con más del 90% de adopción. La decisión está tomada.

### Razones documentadas
| Criterio | Git | SVN |
|----------|-----|-----|
| Adopción industria | ✅ 90%+ | ❌ Legacy |
| Trabajo offline | ✅ Sí | ❌ No |
| Branching | ✅ Liviano | ❌ Costoso |
| Integración CI/CD | ✅ Nativa | ⚠️ Limitada |
| Curva aprendizaje | ⚠️ Media | ✅ Simple |
| Ecosistema (GitHub/GitLab) | ✅ Enorme | ❌ Limitado |

### Plan de capacitación para el equipo
**Semana 1:** Comandos básicos
```bash
git clone, git add, git commit, git push, git pull
```
**Semana 2:** Trabajo con ramas
```bash
git branch, git checkout, git merge, git rebase
```
**Semana 3:** Flujo colaborativo
```bash
Pull Requests, Code Review, resolución de conflictos
```
